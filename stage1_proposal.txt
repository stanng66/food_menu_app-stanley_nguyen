- The topic/theme of my react application is a food menu app, concept was drawn from similar concepts to restaurants digital menus kiosk, restaurant web page menu, as well as online food delivery apps. 
- This application help users browse food items in an organized and user-friendly way. 
- Components I plan to utilize are the header and footer, category filter, shopping cart, menu items (individual food items), and menu list (contains an array of information for food items). 
- The header displays the title of the web application and has a small shopping cart indicator showing how many items the user has selected.  
- This menu app has a category filter to organize and categorize menu items base on type (such as appetizer, desserts, main course, drinks)
- Menu item displays each item individually with its description along with a button for if a user wants to add items to the cart (such as vegan burger, fried chicken burger, vanilla ice cream).
- The menu list displays all available food items to the user. Each food item shows its name, category, and price. This helps users browse the menu and choose what they want to order. 
- The shopping cart counter updates when user adds or removes items, displays how many items the user have selected. 
- The shopping cart counter updates when a user adds or removes items, displaying how many items the user has selected.
